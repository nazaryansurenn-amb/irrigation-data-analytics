\# Database Dictionary



\## dbo.WaterUser

Stores registered water users in the irrigation/WUA system.



Columns:

\- WaterUserID: unique water user identifier

\- WaterUserKod: water user code/account number

\- WaterUserName: name of farmer, person, or organization

\- WaterUserUnitsID: possible link to service unit or land unit

\- WuaID: Water Users Association identifier

\- WaterUserPhone: contact phone

\- WaterUserAddress: user address

\- EnterDateTime: record creation date
